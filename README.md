## About Me

<table>
<tr>
<td width="65%" valign="top">

I'm a **software engineering student** from Sapezal, Mato Grosso (Brazil), starting my path in programming.

My main project, **[Anamnesia](https://github.com/GabezFC/Anamnesia)**, is a local-first memory gateway for AI agents. Its core idea is simple: a retrieval filter that "saves" context but burns more tokens than it saves is not a saving. So every number in the project is **measured, tested and reported, including the optimizations that failed**.

I build with AI coding assistants and put my effort where it matters most to me: **architecture, tests and verifying that things actually work**.

</td>
<td width="35%" valign="top">

**Right now**

- Python backend and CLI tooling
- AI agents, MCP and retrieval
- Benchmarks and honest metrics
- Front-end with plain JS and PWAs

## Featured Projects

<table>
<tr>
<td width="50%" valign="top">

### 🧠 Anamnesia

A local-first **memory gateway for AI agents**: retrieves notes from a Markdown vault, filters them with a paid relevance judge and records **exactly what every query costs in tokens**.

- Deterministic free stages first, paid judge only on what is left
- Reproducible benchmark with a 520-note synthetic corpus and 120 questions
- REST API, MCP server, CLI and dashboard

**Tech:** Python • FastAPI • MCP • Docker • pytest • Vanilla JS

### 🐉 RPG-Vael

An installable **web app (PWA) companion for a dark fantasy tabletop RPG**: conditions, an inventory with carry limit and loot slots, built without frameworks.
